# SAP-C02 背考助手

AWS Certified Solutions Architect – Professional（SAP-C02）备考用的纯静态网页，无需构建。

## 功能

- **方法论**：四步审题法、33 条审题/选项/关键词妙招、按考试领域的决策顺序、易混产品对决表、数字速记、陷阱清单。规律来自对 683 道题的统计，每条妙招都挂了例题号。离线阅读版见 [`docs/SAP-C02-方法论.md`](docs/SAP-C02-方法论.md)。
- **真题库**：在浏览器里导入个人题库 CSV（数据只存在本机），支持按主题/可靠题/待核验/多选/错题筛选，背题模式与练习模式，练习时可先看“题干抓手”提示。
- **闪卡**：内置 63 张知识卡，按 Leitner 间隔重复安排复习。
- **练习题 / 错题本**：内置 28 道场景题，答错自动进入错题本。
- **关键词速查**：“题干关键词 → 答案服务”映射，可搜索。

## 使用

```bash
python3 -m http.server 8000
# 浏览器打开 http://127.0.0.1:8000/
```

也可以直接双击 `index.html` 打开（此时真题库需要手动点“导入 CSV”）。

### 导入题库

CSV 至少需要 `原题号`、`原题干`、`全部选项`、`题库答案` 四列；推荐同时包含 `主题分类`、`题干抓手`、`答案联想`、`关联记忆短句`、`多选拆记`、`核验状态`、`核验备注`、`原解析`。`全部选项` 的格式为 `A：……；B：……`。

把文件命名为 `bank.csv` 放在本目录下，用 HTTP 服务打开时会自动加载。`*.csv` 已加入 `.gitignore`，不会被提交。

### 修改方法论

编辑 `methods.js` 后运行 `node tools/gen-method-doc.js` 重新生成 Markdown 文档。
